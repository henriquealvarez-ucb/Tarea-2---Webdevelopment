# Guía de instalación, configuración y ejecución — Club Frontón (Tarea 2)

Proyecto compuesto por dos aplicaciones independientes que se comunican por REST:

- `backend/` — API REST en NestJS + TypeORM + PostgreSQL, con autenticación JWT.
- `frontend/` — SPA en React + Vite + Tailwind CSS, consumida con Axios.

## 1. Requisitos previos

- **Node.js 20 o superior** (y npm).
- **PostgreSQL** instalado y corriendo localmente (o accesible por red).
- Git, para clonar el repositorio.

## 2. Clonar el repositorio

```bash
git clone https://github.com/henriquealvarez-ucb/Tarea-2---Webdevelopment.git
cd Tarea-2---Webdevelopment
```

## 3. Configurar la base de datos (PostgreSQL)

Crea el usuario y la base de datos que usará el backend. Con `psql`:

```sql
CREATE USER fronton_user WITH PASSWORD 'fronton_pass';
CREATE DATABASE fronton_tarea2 OWNER fronton_user;
```

> Puedes usar otro usuario/base/contraseña; solo ajusta las variables de entorno del backend en el siguiente paso.

Las tablas se crean automáticamente al levantar el backend (TypeORM con `synchronize: true`) — **no hace falta correr migraciones manuales**.

## 4. Configurar y ejecutar el Backend

```bash
cd backend
cp .env.example .env
npm install
```

Revisa/ajusta el archivo `.env` generado:

| Variable | Descripción | Valor por defecto |
|---|---|---|
| `PORT` | Puerto donde escucha la API | `3000` |
| `CORS_ORIGIN` | Origen permitido (el frontend) | `http://localhost:5173` |
| `DB_HOST`, `DB_PORT`, `DB_USERNAME`, `DB_PASSWORD`, `DB_NAME` | Conexión a PostgreSQL | ver `.env.example` |
| `JWT_SECRET` | Secreto para firmar los tokens | *(cambiar en producción)* |
| `JWT_EXPIRES_IN` | Expiración del token | `8h` |
| `SEED_USER_EMAIL`, `SEED_USER_PASSWORD` | Credenciales del usuario demo sembrado al arrancar | `admin@clubfronton.com` / `admin123` |

Levanta el servidor en modo desarrollo:

```bash
npm run start:dev
```

Al arrancar, el backend:
- Se conecta a PostgreSQL y crea las tablas automáticamente.
- Siembra (si no existe) el usuario administrador con las credenciales de `SEED_USER_EMAIL` / `SEED_USER_PASSWORD` y nombre **"Henrique Alvarez"**.
- Si la tabla de jugadores está vacía, siembra 4 jugadores de ejemplo (Juan Pérez, Ana García, Carlos Rodríguez, María López).

La API queda disponible en `http://localhost:3000`.

### Verificar que el backend funciona

```bash
curl -X POST http://localhost:3000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@clubfronton.com","password":"admin123"}'
```

Debe responder con un `accessToken` y los datos del usuario.

## 5. Configurar y ejecutar el Frontend

En otra terminal:

```bash
cd frontend
cp .env.example .env
npm install
```

Revisa el `.env`:

| Variable | Descripción | Valor por defecto |
|---|---|---|
| `VITE_API_URL` | URL base de la API del backend | `http://localhost:3000` |

Levanta el servidor de desarrollo:

```bash
npm run dev
```

La aplicación queda disponible en `http://localhost:5173`.

## 6. Usar la aplicación

1. Abre `http://localhost:5173` en el navegador.
2. Inicia sesión con el usuario sembrado (por defecto `admin@clubfronton.com` / `admin123`).
3. Navega a **Panel principal** (dashboard con estadísticas), **Jugadores** (listado + alta/edición/eliminación) y **Partidos** (listado + alta/edición/eliminación, partidos 2 contra 2 con un máximo de 16 tantos por equipo).
